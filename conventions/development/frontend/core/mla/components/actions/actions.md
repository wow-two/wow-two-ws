# Actions

*Last updated: 2026-10-01*

> Which trigger to reach for, and with what values — the application register over the SDK's action group.
> Use case — choosing between two buttons that would both work, or fixing a value one of them takes.
> What an action is → [action](../../constructs/visual/action.md).

## Components

| Component | Reach for it when |
|---|---|
| [BackToTopButton](backToTopButton.md) | the page is long enough that its top scrolls out of reach |
| [Button](button.md) | the command has no more specific button in this folder |
| [ButtonGroup](buttonGroup.md) | adjacent commands read as one connected control |
| [CopyButton](copyButton.md) | the command writes text to the clipboard |
| [DisclosureButton](disclosureButton.md) | the button expands and collapses a region |
| [FabButton](fabButton.md) | one floating command sits over the screen's content |
| [GoogleSignInButton](googleSignInButton.md) | sign-in runs through Google's ID-token flow |
| [LinkItem](linkItem.md) | the trigger moves to a destination rather than running a command |
| [OptionTileGroupField](optionTileGroupField.md) | a tile grid needs a name and a group-wide disabled state |
| [OptionTilePicker](optionTilePicker.md) | the option reads as a glyph or swatch in a preset grid |
| [SegmentedPicker](segmentedPicker.md) | redirects selection guidance to [ToggleGroup](toggleGroup.md) |
| [SpeedDialGroup](speedDialGroup.md) | one floating anchor offers several commands |
| [ToggleGroup](toggleGroup.md) | a strip of toggles owns one selection |
| [ToggleInput](toggleInput.md) | the pressed state persists as a mode |
| [Toolbar](toolbar.md) | a strip of commands shares one tab stop |
