# Kbd

*Last updated: 2026-09-10*

> One key cap — the glyph a reader presses.
> What a display is → [display](../../constructs/visual/display.md).

## Reach for it when

- must name a single key inside running copy or a menu row
- must hold exactly one key; a combination is a sequence of them

---

## Instead of

| Reach for | When |
|---|---|
| [KeyboardShortcut](keyboardShortcut.md) | the shortcut is more than one key |
| [Code](code.md) | the glyph is a literal in code rather than a key press |
