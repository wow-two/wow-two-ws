# Quote

*Last updated: 2026-09-10*

> The block quote — copy taken from somewhere else, set off by a rule.
> What a display is → [display](../../constructs/visual/display.md).

## Reach for it when

- must set off copy that came from a person, a document, or a review
- should carry the attribution outside it; the block styles the quote only

---

## Instead of

| Reach for | When |
|---|---|
| [Text](text.md) | the copy is the page's own prose |
| [Code](code.md) | the block is a program rather than a sentence |
| `Callout` | the block is the app's own aside rather than a quotation |
