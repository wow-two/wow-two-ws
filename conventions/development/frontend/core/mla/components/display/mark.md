# Mark

*Last updated: 2026-09-10*

> The highlighted run inside other copy — a semantic `<mark>`.
> What a display is → [display](../../constructs/visual/display.md).

## Reach for it when

- must tint one run inside a longer line — a match, a mention, a callback
- must mark a run already isolated in the markup; it never searches the text

---

## Instead of

| Reach for | When |
|---|---|
| [Highlight](highlight.md) | the runs are found by a query rather than hand-wrapped |
| [Text](text.md) | a `color` role says what the run means, without a tint behind it |
| [AnnotationMarker](annotationMarker.md) | the run opens a comment thread when clicked |
