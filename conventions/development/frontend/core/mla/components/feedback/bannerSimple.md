# BannerSimple

*Last updated: 2026-09-10*

> The pinned strip's surface with free-form children — full-width, tone-driven, no structure.
> What a feedback component is → [feedback](../../constructs/visual/feedback.md).

## Reach for it when

- must own the strip's whole row — a countdown, an inline form, a set of links
- must be the base a product-side banner composes on, when it ships its own layout

---

## Instead of

| Reach for | When |
|---|---|
| [Banner](banner.md) | icon, title, description and actions are the layout wanted |
| [AlertSimple](alertSimple.md) | the note belongs to one section rather than the app |
