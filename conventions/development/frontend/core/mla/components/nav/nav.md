# Nav

*Last updated: 2026-09-10*

> Which nav component to reach for, and with what values — the application register over the nav kind.
> What a nav component is → [nav](../../constructs/visual/nav.md).

## Components

| Component | Reach for it when |
|---|---|
| [Breadcrumb](breadcrumb.md) | the page's place in a hierarchy has to be shown and climbed |
| [CommandPalette](commandPalette.md) | there are more actions than a reader can browse, so they type instead |
| [ContextMenu](contextMenu.md) | a right-click or long-press over a region opens the commands |
| [DropdownMenu](dropdownMenu.md) | a visible button opens a short list of rows |
| [Menu](menu.md) | the anchor and the open state are owned by the caller |
| [Menubar](menubar.md) | several command menus share one strip and one open slot |
| [NavItem](navItem.md) | a destination stands in a sidebar across routes |
| [NavigationMenu](navigationMenu.md) | top-level sections sit in a strip, some dropping a rich panel |
| [Pagination](pagination.md) | an ordered set is split into pages the reader steps through |
| [ScrollSpy](scrollSpy.md) | only the id of the section in view is needed, with nothing rendered |
| [TableOfContents](tableOfContents.md) | a long document needs a jumpable outline that tracks the scroll |
